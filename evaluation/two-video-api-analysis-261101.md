# 프로젝트 영상 두 개의 실제 API 시험 (2026-11-01)

현재 Docker의 `POST /api/v1/transcriptions?language=en`에 원본 파일을 각각 한 번씩
순차 업로드했다. STT·번역 동시 처리는 구현하지 않았으며 기존 운영 설정을 사용했다.

## 시간과 반환 결과

| 영상 | 영상 길이 | 전체 요청 | STT | 번역 | 반환 / 묶음 | 생성 시도 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| MIT8_01F16_W06PS01-2_360p.mp4 | 212.587초 | 105.182초 | 33.112초 | 71.656초 | 17 / 17 | 17 |
| ocw_미적분_1.mp4 | 330.908초 | 124.698초 | 39.292초 | 80.160초 | 42 / 43 | 45 |

전체 요청은 호스트 HTTP 클라이언트의 업로드 시작부터 전체 응답 수신까지의 시간이다.
STT·번역은 동일 요청 ID의 서버 로그에서 읽었다. 나머지 시간에는 멀티파트 수신,
파일 저장, 응답 등의 비용이 있다. STT 값에는 오디오 디코딩과 특징 추출이 포함된다.
로켓은 약 21.7MB, 미적분은 약 389.9MB다. 서버 임시 파일 저장 시간은 각각
0.098초·2.507초이며 업로드 전체 시간과 같은 지표는 아니다.

두 요청 모두 HTTP 200이었다. 미적분의 부분 실패 한 개는 응답에
`translation=null`, `translation_error=translation_failed`로 남았다.
로켓은 재시도 없이 끝났고 미적분은 두 묶음이 추가 시도를 해 총 45회 생성했다.

## 미적분의 실패와 품질 문제

- **71.83초부터 79.21초:** `And the first one is the geometric interpretation.`
  두 번 모두 `missing_number`로 거부됐다. 실제 거부된 생성 원문은 운영 로그나 응답에
  없으므로 정확한 후보 내용은 알 수 없다. 다만 모델을 호출하지 않고 현재 검증기에
  정상 번역 예시 `첫 번째는 기하학적 해석입니다.`를 넣어도 같은 오류가 재현됐다.
  `one`을 수량으로만 검사하는 규칙의 오탐을 확인한 진단이다.
- **10.00초부터 21.73초:** `hundreds of MIT courses`를 `백만 개의 MIT 강좌`로
  옮겨 수량을 잘못 바꿨지만 검사에 통과했다.
- **97.82초부터 113.33초:** 현재 영어는 미적분이 기초 과목인 이유를 설명하는데,
  번역은 앞 문장의 도함수 물리적 의미 설명을 반복했다. 현재 원문의 상당 부분이 빠졌다.
- **241.98초부터 273.68초:** 접선 문제를 설명하는 한 발언이 세 번역 묶음으로
  끊겼다. 마지막은 `함수는 어떤 점, 예를 들어 x₀에서 y₀에서 정의된다 합니다.`로
  번역돼, 원문에 없는 정의 설명과 문법 결함이 생겼다. 첫 생성의 `informal_speech`
  거부 후 재시도 출력이 기존 검사를 통과한 사례다.
- **300.88초부터 304.20초:** `some point`를 `몇 개의 점`으로 옮겨 단일 점을
  여러 점으로 바꿨다.

실패 한 개 외에도 검사에 통과한 오역이 있다. 위 검토는 반환된 영어 STT와 한국어를
대조한 것이며, 전체 영상의 음성·판서를 정답으로 전사하거나 번역 정확도를 점수화한
평가는 아니다. 특히 긴 설명이 끊기는 문장 묶기와 숫자·반말 검증의 한계가 드러났다.
이번 작업은 시험과 분석만 수행했으며 해당 규칙을 수정하지 않았다.

## 로켓 영상의 검토 범위

17개 모두 반환됐고 대량 실패나 관계없는 설명으로 바뀌는 현상은 관찰하지 못했다.
다만 수학 발언에는 직역과 모호성이 남는다. 예를 들어 `all primes`를
`이 모든 것이 모두 프라임입니다`로 옮기고 수식 설명을 직역한다.
`u1 over m`, `mr dvr equals dmru` 같은 STT 표기는 원래 판서와 대조하지 않았으므로
번역이 반환됐다는 사실만으로 수식 정확성을 보장할 수 없다.

기존 저장 기준 자막과 영어 STT의 단어 편집 차이는 369단어 중 51개, WER 13.82%다.
기준 자막 자체에도 수식·발화 표기의 불확실성이 있으므로 이를 번역 정확도로
해석하지 않는다. 미적분에는 같은 방식의 전체 정답 자막 비교를 수행하지 않았다.

## 환경·검증과 자료

Mac ARM64 Docker, VM 8 vCPU·약 6GB, STT Small CPU INT8·4CPU,
번역 Qwen3-4B-Instruct-2507 Q4_K_M·8CPU·8스레드 조건이다.
두 모델 객체는 처음부터 로드돼 있었으나 별도 워밍업 요청을 하지 않았다.
페이지 캐시·실제 상주 메모리·호스트 발열·주파수는 고정하지 않았다.
각 영상 한 번의 관측값이며 Windows AMD64 성능 검증이나 반복 측정 평균이 아니다.

실제 Docker 컨테이너의 공개 소스·용어집 SHA256 11개가 저장소와 같음을 확인했다.
두 응답의 시각은 범위 안에서 양수 길이·순서·비중첩 검사를 통과했다.
요청 전후 서버 이미지·명령·자원·컨테이너 ID·정상 상태는 같았고 OOM·재시작은 없었다.
전체 테스트 모음은 실행하지 않았고 Git 커밋도 수행하지 않았다.
