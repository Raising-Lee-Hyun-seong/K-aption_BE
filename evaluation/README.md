# 물리학 번역 품질 평가

아래 기존 평가일은 2026-10-03이다. 2026-10-04의 문장 묶기·영어 문맥·스트림 검증 결과는 문서 뒤에 별도로 기록한다. 모델은 기존 KoreanLM MLX 4bit이며 교체하지 않았다.

**최종 샘플 결과: 36묶음, 번역 176.13초, 검증 수락 22개·실패 14개, 원문 의미 보존 10/36. 번역 품질 기준은 미통과다.** 의미 판정은 Codex가 원문·출력을 대조한 검토이며 독립 전문가 검수 전이다.

## 평가 자료와 방법

- `../data/physics_glossary.json`: 기존 평가 당시 20개, 현재 28개. 원문에서 단어 경계로 매칭하며 겹치는 위치는 긴 복합 용어를 우선한다.
- `physics_cases.json`: 프로젝트 평가용 합성 영어 문장·기준 번역 12개. 용어 20개 전체를 평가하는 데이터는 아니며 후속 확대가 필요하다.
- `baseline.json`: 커밋 `40bed6d`의 번역 서비스로 측정한 개선 전 결과.
- `improved.json`: 2026-10-03 서비스의 문장별 결과. 현재 구현의 재평가 결과와 구분한다.
- `prompt-alternative.json`: 직역·주어·숫자 보존 지시를 사용한 비교 실험. 질량 문장에 부정을 추가하는 오류가 나타나 채택하지 않았다.
- `lecture.json`: 저장소 강의 영상 전체의 STT·번역 결과와 시간.

기존 평가에서는 동일한 문장, 모델, 최대 출력 128토큰, 결정적 샘플러를 사용했다. 일부 문장에 이전 한국어 문맥을 지정해 복사를 검사했다. 기존 강의 평가는 당시 API처럼 이전 성공 번역을 다음 구간에 전달하며 실패하면 문맥을 초기화했다. 현재 API는 앞 영어 원문을 문맥으로 사용한다.

## 의미 정확도는 미통과

용어 포함은 의미 정확성과 다르다. 다음 오류는 최종 평가에서 직접 확인되었다.

| 원문 | 실제 출력 | 문제 |
| --- | --- | --- |
| The net force acting on the object is zero. | 알짜힘이 작용하는 것이 아니라면 입자의 움직임이 없습니다. | 알짜힘 0을 조건과 운동 없음으로 바꾸고 물체를 입자로 변경 |
| Speed is the magnitude of velocity. | 속도는 속력의 크기입니다. | 속력과 속도의 관계를 뒤집음 |
| Displacement differs from distance traveled. | 변위는 거리를 넘어 이동하는 것과 달리 움직이는 것입니다. | 변위·이동 거리의 차이를 제대로 설명하지 못함 |
| Impulse is the change in momentum. | 운동량은 충격량으로 변경됩니다. | 충격량과 운동량 변화의 관계를 왜곡 |

따라서 현재 결과로 정확한 강의 번역을 보장하지 않는다. 모델은 교체하지 않았으며, 모델 변경이나 외부 API 도입은 별도 작업 범위다.

## 전체 강의 평가

입력 영상은 212.59초(약 3분 33초)이며 STT 구간 45개를 처리했다.

| 항목 | 결과 |
| --- | --- |
| 모델 로딩 | 3.45초 |
| STT(지연 모델 로딩 포함) | 21.30초 |
| 번역(재시도 포함) | 221.71초 |
| 위 세 단계 시간 합 | 246.46초 |
| 번역 검증 통과 구간 | 44/45 |
| 번역 검증 실패 구간 | 1 |

**44개 구간의 검증 통과는 정확한 번역 44개를 뜻하지 않는다.** 31~33번 구간에는 버스 운행 최적화라는 무관한 내용과 반복 표현이 생성됐고, 40번 구간은 번역 지시와 문맥을 출력에 포함했다. 현재 표식·용어·완전 일치 검증만으로는 이 오류들을 거부하지 못한다. 2번 구간은 출력 검증 실패로 기록됐으며 이후 구간은 계속 처리했다.

숫자·단위·부분 문맥 복사·지시 노출을 검증하는 후속 평가와 문장 단위 STT 재구성이 필요하다. 전체 결과의 원문과 출력은 `lecture.json`에 보존했다.

## 검증과 한계

- 회귀 테스트 18개 통과: 용어 누락 재시도, 문맥 복사 거부, 단어 경계·복합 용어 우선순위, 화살표 뒤 한국어 보존과 기존 API 계약 포함.
- 번역 실패는 기존 API 계약의 `translation_failed`로 전달된다.
- 용어 표기 검증은 공백을 무시하지만 별칭·동의어는 지원하지 않는다.
- 문맥 검증은 공백을 제외한 완전 일치만 탐지한다. 일부 표현 반복, 설명 덧붙이기 및 의미 오류는 통과할 수 있다.
- 앞 문장과 같은 번역이 정상인 반복 발화도 검증 실패로 표시할 수 있다.
- 문맥은 마지막 256자로 제한한다. 긴 강의의 문장 연결·화자 문맥은 별도 개선이 필요하다.
- 현재 저장소 영상은 약 3분 33초다. 5~10분 영상 검증은 자료 부족으로 수행하지 못했다.

## 기존 평가에서 제안한 품질 작업

1. 용어 포함뿐 아니라 수치·부정·주어·물리 관계 보존을 사람이 판정한 평가 항목을 확대한다.
2. 끊어진 STT 구간을 문장 단위로 묶고 번역 후 원래 자막 구간에 배분하는 방식을 검증한다.
3. 용어 별칭과 반복 발화 예외를 지원하고, 설명·문맥 복사의 변형을 탐지한다.
4. 기존 모델의 개선 한계를 평가 데이터로 확인한 뒤 후속 모델 선택을 논의한다.

## 2026-10-04 구현과 평가 방법

- 공식 자막: `mit_rocket_reference.json`. [MIT OCW 원본](https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/resources/rocket-sled-integrate-the-rocket-equation/)의 VTT 42구간이며 출처·라이선스·SHA256·오기 가능성을 기록했다.
- 기준 번역: `mit_rocket_cases.json`. 공식 발화 10개와 수동 한국어 기준·숫자·수식·행위·부정·비교 관계 검토 항목을 제공한다. 독립 전문가 검수 전이다.
- 평가 도구: `../scripts/evaluate_lecture_quality.py`. 저장 STT와 공식 영어 자막을 같은 모델로 별도 번역하며 기존 조각별 번역·시간을 연결해 보존한다.
- 문장 묶기: 공식 42→24, 저장 STT 45→36그룹. 문장 끝·18초·350자·2초 초과 공백에서 닫고 원래 시각 범위를 보존한다. STT가 문장 중간에 마침표를 찍은 경우는 여전히 끊길 수 있다.
- 문맥: 앞 그룹의 영어 원문 마지막 256자를 전달하며 실패 뒤에도 유지한다.
- 검증: 용어 28개, 지원 수식 기호, 명시적 숫자·부호, 일부 길이·질량 단위를 검사한다. 반복·지시문 표식·손상 문자를 스트림에서 발견하면 조기 종료하고 문맥 없이 한 번 재시도한다. 128토큰 상한에서 끝난 출력은 수락하지 않는다.

공식 자막 대비 저장 STT의 단어 편집 오류는 57/369=15.45%이며 단어 시퀀스 유사도는 0.8842다. **음성 인식 정확도 지표로 사용할 수 없다.** 공식 자막의 `arrived`, `2vr`, `lm` 등 오기 가능성과 `m r`/`mR` 같은 수식 띄어쓰기 차이가 포함된다. 원문을 임의로 정답 수식으로 보정하지 않았다.

```bash
.venv-api/bin/python scripts/evaluate_lecture_quality.py --output evaluation/lecture-quality.json
```

STT는 재실행하지 않으며 모델 로딩·번역 시간만 새로 측정한다. 공식 번역을 먼저 실행하므로 뒤의 STT 번역에는 워밍업 영향이 있을 수 있다. 이전 `lecture.json`과 입력 묶음·문맥·출력 검증이 달라 실행 시간과 검증 수락 건수를 정확도 개선율로 해석하지 않는다.

STT 번역 시간은 최초 1회 재평가에서 34.46초(약 15.5%) 줄었다. STT는 저장 결과를 사용했으므로 기존의 모델 로딩+STT+번역 단계 합 246.46초와 새 번역 시간을 직접 비교하거나 전체 처리 시간을 새로 측정했다고 말할 수 없다. 이번 모델 로딩은 5.22초였다.

수동 기준은 핵심 행위·대상·수치·변수·부정·비교·연산관계 보존이며 무관한 내용 추가가 있으면 미통과다. **수락된 STT 출력 27개 중 15개는 의미 오류가 있고 1개는 원문이 불명확했다.** 공식과 STT의 입력 경계·오기가 달라 두 통과율의 우열을 직접 비교하지 않는다. 독립 전문가 검수나 블라인드 반복평가는 수행하지 않았다.

| 관찰 | 근거 |
| --- | --- |
| 일부 용어·단위는 개선 | STT 4 적분, 20 건조 질량+연료 질량+2m0, 21 2m0 무단위 |
| 변수 문자열을 포함해도 오역 가능 | STT 6의 mR=메트릭, dvR=디지털 비트 |
| 프라임·나눗셈 관계 오역 | STT 14 소수, 23 프리미엄, 10 dmR 위에 mR |

`rejection_reasons`는 시도 단위 건수이며 실패 구간 수와 다르다. 모델은 그대로 유지했다. 공식 영어 원문에서도 오류가 다수 발생해 STT만 고치는 것으로 번역 품질을 해결할 수 없다.

## 평가 중 발견한 검증 보완

숫자에 붙은 단위와 계수(2kg, 2dmR), 부호 사이 공백, 1,000/.5 표기, 영·두 같은 한글 수사 활용의 오탐을 보완했다. m/g는 숫자와 붙은 경우에만 짧은 단위로 인식해 변수와의 충돌을 줄인다. 복합 영어 수사(one hundred 등), 과학적 지수 표기, 수식 전체의 연산·인자 관계를 검증하는 기능은 제공하지 않는다.

새로 관찰된 `(참고만 하세요.)`, `원문을 한국어로 번역` 지시문 유출과 단위 오류에 걸리는 기존 수락 출력 4개를 `lecture-quality-recheck.json`에서 재생성했다. 이는 부분 평가이므로 전체 번역 시간을 대체하지 않는다. official-2는 재시도에서 변수분리+적분을 보존했지만 official-4·5·17은 여전히 행위·수식 관계를 오역했다. 유출을 막는 것이 의미 정확성을 보장하지 않는다는 결과다.

수식의 띄어쓴 변수·프라임 검증을 추가했다. `d v r/dvR`, `d m r/dmR`, `m r/mR`, `v r/vR`의 별칭과 `dmRu/dmR u`, 독립 변수를 검사하며 수학 문맥의 prime을 소수·프리미엄으로 바꾼 결과는 거부한다. 원문 자체는 수정하지 않았다.

## 최종 코드의 샘플 재평가

결과는 `lecture-quality-current.json`이다. 공식 자막을 먼저 번역하지 않고 저장 STT 36묶음만 최종 코드로 다시 실행했다. 앞 영어 문맥·최대 128토큰·기존 모델은 유지했다.

최종 의미 검토는 `lecture-quality-current-review.json`에 원본 SHA256·구간별 근거와 함께 기록했다. 원문 의미 보존은 10/36이고 검증 수락 22개 중 12개에는 의미 오류가 남았다. 기준은 최초 검토와 같으며 변경된 출력 7개를 모두 확인했다. 이 수치는 STT 원문에 대한 충실성 검토로, 실제 음성 대비 정확도를 뜻하지 않는다.

| 지표 | 기존 조각별 결과 | 최종 코드 |
| --- | --- | --- |
| 입력 번역 단위 | 45 | 36 |
| 번역 시간 | 221.71초 | 176.13초 |
| 자동 검증 수락 | 44 | 22 |
| 번역 실패 표시 | 1 | 14 |
| 시도 수 | 기록 없음 | 52 |
| 엄격한 원문 의미 보존 | 동일 기준 재판정 안 함 | 10/36 |

1회 측정의 번역 시간이 45.58초(약 20.6%) 줄었다. 출력 길이·재시도·조기 중단·캐시·장비 상태와 실패 구간 수가 달라 일반적인 성능 개선율로 해석하지 않는다. STT를 재실행하지 않았으므로 전체 API 처리 시간은 새로 측정하지 않았다.

기존에 수락되던 메트릭/디지털 비트·소수/프리미엄 출력은 최종 평가에서 실패로 표시됐다. 반면 STT 25는 변수를 보존하면서 뺄셈을 곱셈으로 바꾼 오역을 반환했다. 변수·숫자 보존 검사는 수식 전체의 연산 관계를 보장하지 않는다. 의미 품질 기준은 여전히 미통과다.

최종 회귀 테스트 58개와 전체 프로젝트 Python 24파일의 모듈·클래스·함수 한국어 docstring 검사를 통과했다. 모델 가중치·어댑터는 변경하지 않았으며 커밋하지 않았다. 실행 중인 서버에는 재시작 후 반영된다.

## 남은 우선순위

1. 현재 모델·토크나이저·템플릿·LoRA 어댑터 사용 여부를 원본 구성과 대조한다. 설정 변경·모델 교체에 앞서 문제와 기대 효과를 확인한다.
2. 수식 전체의 관계·부정·문장 간 바꿔 쓴 반복을 판정하는 평가를 확대하고, STT의 잘못된 문장 끝·로켓 썰매 인식을 개선한다.
3. 실제 시도 로그에 따라 출력 토큰 한도·재시도 정책·프롬프트 캐시·재처리 캐시를 비교한다. 시간 단축은 의미 정확도·실패 구간 수와 함께 평가한다.
4. 작업 ID·진행률·결과 스트리밍 및 SRT/VTT 출력을 연결한다.

## 모델 구성 대조에서 확인한 차이

[KoreanLM 공식 추론 예시](https://github.com/quantumaikr/KoreanLM#추론)와 [공식 추론 코드](https://github.com/quantumaikr/KoreanLM/blob/main/generate.py)는 `quantumaikr/KoreanLM`에 `quantumaikr/KoreanLM-LoRA`를 적용한다. 현재 준비 스크립트는 원본 모델만 FP16으로 변환하고 Makefile은 해당 폴더를 그대로 4bit로 양자화한다. API 서비스는 `load(str(model_path))`를 호출하며 어댑터 로드·병합 경로가 없다. LoRA용 프롬프트 템플릿을 쓰는 것만으로 어댑터가 적용되지는 않는다.

공식 사용 예시와 현재 API의 어댑터 적용 방식이 다른 것은 확인했다. 이것이 모든 오역의 원인인지, 어댑터를 적용하면 품질이 해결되는지는 아직 검증하지 않았다. 당시에는 어댑터의 공개·다운로드 가능 여부, MLX 호환·병합 방식과 동일 문장 평가를 후속 과제로 제안했다. 해당 구성 대조 단계에서는 모델·어댑터 가중치를 변경하지 않았다.

2026-10-05 사전 점검에서 공식 어댑터의 공개 상태·약 8MB 크기와 다운로드 주소의 HEAD 200 응답을 확인했다. PEFT→MLX 변환 경로는 확인했지만 실제 텐서·추론 호환성 및 품질은 미검증이다. 상세 내용과 다음 실행 순서는 [LoRA 사전 점검](lora_compatibility.md)에 기록했다.

2026-10-05 실제 다운로드·변환에서 SHA256이 일치하는 공식 고정 리비전의 **B 행렬 64개가 모두 0**임을 확인했다. 이 파일은 학습된 변화를 추가하지 않으므로 공개 어댑터를 빠뜨린 것만으로 기존 의미 오류를 설명하거나 복원만으로 개선을 기대할 수 없다. MLX 변환·CPU 계산 및 전체 테스트 66개를 통과했으며 전체 모델은 로드하지 않았다. 다음 우선순위는 실제 학습된 어댑터 확보 가능성·모델 방향 검토다. [실제 파일 점검 결과](lora_conversion.md)를 참조한다.

공식 어댑터의 공개 변경 이력 24개도 확인했다. 가중치가 있는 23개 버전의 SHA256이 모두 동일해 다른 학습 델타를 가진 공개 버전을 찾지 못했다. 공개 LoRA 복구 조사는 완료하고 로컬 번역 모델 후보 비교를 다음 작업으로 제안한다. [이력 조사와 후속 계획](lora_history.md)에 범위·근거·판단을 기록했다.

로컬 비교 후보는 TranslateGemma 4B 4bit와 Qwen3 4B Instruct 2507 4bit로 선정했다. 고정 리비전·공개 파일 용량·설치된 MLX 구현·평가 22문장의 채팅 템플릿을 점검했다. HY-MT는 한국 제외 라이선스 때문에 제외했다. 가중치·번역 품질은 아직 미검증이다. [후보 비교와 실행 계획](model_candidates.md)을 참조한다.

## 두 후보 실행 비교 결과

TranslateGemma 4B·Qwen3 4B Instruct를 M4·16GiB에서 22문장씩 두 번 실행했다. 엄격한 의미 보존은 각각 8/22·15/22이고 두 모델 모두 자동 검사 문제 없음은 21/22였다. 속력·충격량 등의 의미 오류는 자동 검사를 통과했다. 22문장 번역 시간은 각각 18.45~18.53초·18.78~18.92초, MLX 프로세스 최고 할당 메모리는 2.36GB·2.47GB였다. 기존 강의 평가와 조건이 달라 개선율로 비교하지 않는다. TranslateGemma의 EOS·RoPE 설정 대응 및 진단 실행을 분리해 보존했다. 테스트 71개 통과. [실행 결과와 문장별 판정](candidate-comparison.md)을 참조한다. API 교체는 하지 않았다. 다음은 Qwen3에 용어집·수식 보존 지시를 적용한 소규모 재평가다.
