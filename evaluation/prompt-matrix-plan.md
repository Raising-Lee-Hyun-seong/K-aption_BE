# 모델·프롬프트 비교 실험 계획

평가일: 2026-10-10. 입력은 기존 공식 MIT 강의 10문장과 합성 물리학 12문장, 총 22개다. 기준 번역·의미 확인 항목은 모델 입력에 넣지 않는다. 기존 평가 자료의 출처와 라이선스 표시는 그대로 따른다.

| 조건 | 모델 | 지시와 추가 입력 |
| --- | --- | --- |
| koreanlm-current | 기존 KoreanLM 4bit | 현재 API 프롬프트, 매칭 용어·기호 보존 지시, 이전 문맥 없음 |
| koreanlm-simple | 같은 KoreanLM 4bit | 기존 한국어 템플릿과 짧은 번역 지시만 사용 |
| qwen-base | 기존 Qwen3 4B Instruct 2507 4bit | 기존 후보 평가의 원문·부정·숫자·수학 관계 보존 지시 |
| qwen-glossary | 같은 Qwen3 | 기준 지시에 연산·부등호·정정·대상·평서/질문 보존 지시와 원문 매칭 용어 추가 |

각 조건은 독립 프로세스에서 한 모델만 로드한다. 동일한 순서로 예열 1문장을 제외하고 22개를 두 번 생성한다. temperature=0, 최대 생성 256토큰, 입출력 합계 제한 2048토큰, 이전 문맥·재시도·조기 중단 규칙·출력 정리 없음이다. 출력 전체와 종료·토큰·시간·MLX 최고 할당량을 저장한다. API 모델·프롬프트·가중치는 교체하지 않는다.

원시 생성과 현재 API의 검증·정리·재시도 흐름을 구분한다. qwen-glossary는 용어집과 보존 지시를 함께 바꾸므로 어느 요소가 개선을 일으켰는지는 이 실험만으로 분리할 수 없다. KoreanLM 간소화도 전체 지시 묶음 변경이며 개별 문구의 인과 효과를 입증하지 않는다.

## 판정 기준

- pass: 원문의 대상·행위·관계와 중요한 기호·수량·정정·부정이 보존된다. 합력/알짜힘 등 정상 동의어와 의미를 유지한 자연스러운 재구성은 허용한다.
- partial: 주요 내용을 일부 전달하지만 물리학 용어 구분 또는 변수·관계의 일부가 빠져 엄격한 통과 기준에 미달한다.
- fail: 대상이나 행위·연산·부정·인과를 바꾸거나 의미와 무관한 내용을 추가한다. 출력 잘림·언어 실패·생성 예외도 기록하고 완전한 번역으로 인정하지 않는다.
- speed/velocity는 속력/속도로, mass/weight는 질량/무게로 구분한다. 변수만 남은 출력의 틀린 연산은 통과시키지 않는다. 문구 일치율이나 필수 단어 포함률을 의미 정확도로 사용하지 않는다.
- 단일 Codex 평가자의 원문 대조이며 독립 전문가 검수 전이다. 각 문장의 원문·기준·출력과 판정 근거를 함께 저장한다. 반복 출력이 같으면 의미 판정을 중복 집계하지 않는다.

## 결론 범위

22개 문장에 대한 프롬프트 선택 근거를 제공하며 전체 강의나 다른 전공의 정확도를 일반화하지 않는다. 최상 후보도 기존에 문제였던 대상·속력·충격량·정정·수식 관계를 확인하고 강의 36구간으로 확대 검증한 뒤 API 적용을 판단한다. 테스트 통과와 모델 의미 품질 통과는 별개다.
