# Qwen3 용어·관계 지시와 강의 문맥 보완 결과

보고 기준일: 2026-10-18. **22문장 의미 보존은 기존 19/22에서 보완 조건 21/22가 됐다. 강의 문맥을 별도 시스템 메시지로 분리한 평가에서는 26/36이 의미를 보존했지만, 의미·언어 오류와 STT 파편이 남아 API 교체는 보류했다.** 사람·독립 전문가 검수 전 단일 Codex 평가자의 판정이다.

## 22문장 원시 생성 비교

[사전 계획](qwen-refinement-plan.md)의 세 조건을 기존 로컬 Qwen3 4B Instruct 2507 4bit로 두 번씩 실행했다. 공식 자막 10문장과 합성 물리학 12문장, 온도 0, 최대 256토큰, 입출력 합계 2048토큰, 문맥·재시도·조기 중단·출력 정리 없음이다. 기준 번역과 정답 수식은 입력하지 않았다.

| 조건 | 의미 보존 | 부분 보존 | 언어 문제 | 의미·언어 모두 통과 | 두 회차 생성 시간 | MLX 최고 할당량 |
| --- | ---: | ---: | ---: | ---: | --- | ---: |
| 기존 용어집·보존 지시 | 19/22 | 2 | 0 | 19/22 | 19.98초 / 19.86초 | 2.58GB |
| v2 용어만 추가 | 21/22 | 1 | 1 | 20/22 | 20.27초 / 20.22초 | 2.58GB |
| v2 용어 + 관계 지시 | 21/22 | 1 | 0 | 21/22 | 22.94초 / 23.10초 | 2.68GB |

기존 조건의 44개 출력은 이전 실행과 모두 같았다. 세 조건 각각 두 회차의 22개 출력도 전부 같았다. 시간은 로딩·출처 검증·예열을 제외한 생성 합계이며 시스템 전체 메모리가 아닌 MLX 할당량이다.

- rocket=로켓, magnitude=크기, constant=상수는 [평가 전용 추가 용어](physics_glossary_additions_v2.json)에 보관한다. API의 28개 용어집은 변경하지 않았다.
- 용어 추가 후 로켓 대상과 속력 정의는 보존됐다. 용어만 추가한 조건의 첫 접속사 `并且`는 중국어로 남았다. 의미 보존과 한국어 자막으로서의 언어 적합성을 따로 집계해 이 출력을 사용 가능한 통과에 넣지 않았다.
- 관계 지시까지 추가하면 첫 접속사는 한국어로 생성됐지만, `d v r = u d m r / m r` 연결은 여전히 불완전했다. 해당 문장은 부분 보존이다.
- `M r`를 `M_r`로 표기한 두 보완 조건은 의미 대조에서는 통과했지만 현재 기호 검사에서는 `missing_math_symbol`로 거부됐다. 반대로 기존 등식 오류와 중국어 혼입은 자동 검사에서 통과했다.
- `constant=상수`는 `속도는 상수이다`라는 덜 자연스러운 문장도 만들었다. 의미 보존과 표현 품질을 구분하며, 용어의 품사·문맥 구분이 필요하다.

이 문장들은 이미 알려진 오류를 바탕으로 보완한 개발 세트다. 새로운 강의에 대한 정확도나 개별 용어의 인과 효과로 일반화하지 않는다. 관계 지시 조건을 후속 강의 평가에 사용했다.

원시 실행과 문장별 판정:

- 용어 보완: [원시 실행](qwen-refinement-terms.json), [판정](qwen-refinement-terms-review.json)
- 관계 보완: [원시 실행](qwen-refinement-relations.json), [판정](qwen-refinement-relations-review.json)

## 저장 STT 36구간 평가

평가 전용 `EvaluationQwenService`가 기존 `TranslationService`의 정리·검증·재시도·조기 중단을 상속한다. 모델과 프롬프트만 평가용으로 연결했다. 최대 128토큰, 앞 영어 원문 마지막 256자, 문맥 없는 재시도 1회, 기존 28개 용어 검사를 사용했다. 추가 용어는 프롬프트에만 적용한다.

첫 실행에서 참고 문맥을 사용자 지시에 붙이면 모델이 앞 문장과 안내 표식까지 번역했다. 이 문제를 확인한 뒤 참고 문맥을 별도 시스템 메시지에 두고 현재 원문은 사용자 메시지에 남기는 두 번째 조건을 만들었다. 두 번째 조건은 사후 보완 실험이며 독립 검증이 아니다. 각 강의 조건은 한 번 실행했다.

| 항목 | 지시에 문맥 포함 | 시스템 메시지로 문맥 분리 |
| --- | ---: | ---: |
| 자동 검증 수락 | 35/36 | 34/36 |
| 엄격한 의미 보존 | 6/36 | 26/36 |
| 실패 | 29 | 7 |
| 원문 불확실로 미판정 | 1 | 3 |
| 수락 출력 중 의미·언어 실패 | 28 | 5 |
| 번역 미제공 | 1 | 2 |
| 문맥 안내 표식 유출 | 5 | 0 |
| 전체 시도 수 | 43 | 38 |
| 번역 시간 | 56.03초 | 39.40초 |
| MLX 최고 할당량 | 2.67GB | 2.75GB |

문맥 안내 표식 건수는 앞 문장 의미 반복 전체의 자동 탐지율이 아니다. 출력 길이·재시도·장비 상태가 달라 시간 차이를 일반적인 성능 개선율로 해석하지 않는다. STT는 저장 결과를 재사용했으므로 디코딩·STT·전체 API 시간은 측정하지 않았다. 22문장 원시 생성 결과나 과거 KoreanLM API 실행과 같은 조건이 아니다.

시스템 메시지 조건에 남은 사례:

| 구간 | 남은 문제 |
| --- | --- |
| stt-9 | `goes up front`를 앞에 놓는 행위가 아닌 처음에 증가한다고 번역 |
| stt-14 | prime 보존 검사 실패로 번역 미제공 |
| stt-17 | 불명확한 수식 파편이 한국어 형식 검사에 실패해 번역 미제공 |
| stt-23 | `равно`라는 러시아어 혼입과 불완전한 수식 연결을 자동 검사가 수락 |
| stt-26 | 수학 문맥의 Integrated를 적분 대신 통합으로 번역 |
| stt-28 | `over 2m0`의 나눗셈 관계를 보존하지 못함 |
| stt-35 | sled를 슬라이드로 바꿔 정지 대상을 잘못 번역 |

stt-1의 rocket's lead, stt-8의 끊긴 등식, stt-27의 `So ln`은 미판정으로 두고 통과에 넣지 않았다. 기타 STT 용어·수식 불확실성도 구간별로 기록했다. 출력이 없거나 명백한 추가·왜곡이 있는 경우는 원문 불확실성과 별도로 실패로 처리했다. 수식의 영어 연산어·정상 음역은 의미를 유지하면 허용하되 표현 품질 문제를 기록했다.

- 지시에 문맥 포함: [원시 실행·시도](qwen-refinement-lecture.json), [36구간 판정](qwen-refinement-lecture-review.json)
- 시스템 메시지 분리: [원시 실행·시도](qwen-refinement-lecture-system.json), [36구간 판정](qwen-refinement-lecture-system-review.json)

MIT OCW 강의의 출처·원본 자막·라이선스 정보는 강의 결과의 `lecture_source`와 기존 평가 자료에 보존했다. 원문을 임의로 올바른 수식으로 수정하지 않았다.

## 결정과 다음 작업

**API 모델·프롬프트·용어집은 유지한다.** 평가 도구와 별도 결과만 추가했다. 다음 우선순위는 끊긴 STT 수식 경계, 적분·앞에 놓기·썰매의 의미 보존, 출력 언어 혼입·문맥 유출 탐지, 정상 수식 표기 별칭에 대한 검증 오탐을 개선하는 것이다. 보완 후 개발에 쓰지 않은 강의와 사람 검수로 API 적용 여부를 판단해야 한다.

회귀 테스트 91개를 통과했다. 실제 모델 실행 결과와 단위 테스트 통과는 구분한다. 평가 JSON은 기존 파일 덮어쓰기를 거부하며, 실행 날짜는 `--evaluated-on`으로 명시할 수 있다. 커밋하지 않았다.

## 강의 평가 재현

새 출력 경로를 지정한다. 시스템 메시지 조건은 다음과 같다.

```bash
HF_HUB_OFFLINE=1 HF_HUB_DISABLE_IMPLICIT_TOKEN=1 TOKENIZERS_PARALLELISM=false .venv-api/bin/python scripts/evaluate_qwen_lecture.py --context-format system --evaluated-on 2026-10-18 --output evaluation/qwen-lecture-new-run.json
```

첫 조건을 재현하려면 `--context-format inline`과 다른 출력 경로를 사용한다. 22문장 재현 명령은 [사전 계획](qwen-refinement-plan.md)에 있다.
