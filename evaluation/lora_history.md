# 공식 LoRA 변경 이력과 후속 작업 판단

조회일: 2026-10-05. 공개 HTTP API로 브랜치·커밋·각 리비전의 파일 메타데이터를 확인했다. 전체 모델 추론과 새 가중치 다운로드는 하지 않았다.

## 확인 결과

- 공식 저장소에는 main 브랜치 하나가 있고 태그·변환 브랜치는 없다. 현재 리비전은 `1447f2ae33e32cb8af610758b90adda0c05670a2`다.
- 공개 커밋은 24개이며 커밋 조회 응답에는 다음 페이지 링크가 없다. 각 파일 조회 응답의 sha가 요청한 리비전과 일치함도 확인했다.
- 최초 커밋에는 어댑터가 없다. 나머지 23개 커밋은 모두 같은 8,434,381바이트 어댑터를 가리킨다.
- 23개 버전 모두 SHA256이 `f7f1707df4e86b215ad34347ea3dc9a508c7b46d6f15abf296cd556245aa98fb`이고 설정의 Git blob도 같다.
- 이 해시는 [실제 파일 점검](lora_conversion.md)에서 B 행렬 64개가 모두 0임을 확인한 파일의 해시와 일치한다. 따라서 공개 이력에서 다른 학습 델타를 가진 버전을 발견하지 못했다. 과거 파일 23개를 각각 내려받을 필요는 없다.

공개 저장소와 현재 조회 가능한 이력에 대한 결론이다. 삭제된 이력·비공개 학습 결과·제3자 어댑터의 존재까지 부정하지 않는다. 모든 B가 0인 이유도 확인하지 못했다.

## 판단

기존 모델의 최종 샘플은 원문 의미 보존 10/36으로 기준 미통과다. 공식 영어 자막에서도 의미 오류가 발생했으므로 STT 개선과 문자열 검증 강화만으로 해결되지 않는다. 공개 LoRA 복구 경로는 이번 조회로 조사 완료 처리한다.

| 방향 | 필요한 작업 | 현재 판단 |
| --- | --- | --- |
| 현재 KoreanLM에 공개 LoRA 적용 | 기반 모델 복원·어댑터 적용 | 동일한 영값 파일이므로 개선 평가의 우선순위에서 제외 |
| 현재 KoreanLM 직접 추가 학습 | 학습용 정답·검증용 분리 자료·학습 환경 확보 | 작은 평가 자료만으로 효과를 기대하기 어려워 장기 과제로 유지 |
| 로컬 번역 모델 비교 | 후보의 영어→한국어·라이선스·M4/16GB 실행 지원 확인 후 동일 문장 평가 | 다음 작업으로 권장. 후보 조사와 실제 모델 교체를 구분 |
| 외부 번역 API 비교 | 외부 업로드·비용 조건 합의, 동일 문장 품질·시간 측정 | 사용자 선택에 따라 비교. OpenAI를 사용하면 승인된 gpt-4o-mini 유지 |

## 다음 실행 계획

1. 우선 로컬 후보 2개 내외의 공식 자료를 검토해 영어→한국어 지원, 실행 방식, 다운로드 크기, 라이선스와 M4·16GB 제약을 비교한다. 한국어 지원만으로 물리학 번역 정확도를 추정하지 않는다.
2. 후보와 실행 범위가 정해지면 모델을 준비하고 공식 기준 문장 10개·기존 물리학 문장 12개로 소규모 품질 평가를 먼저 수행한다. 기준 번역은 독립 전문가 검수 전임을 표시한다.
3. 용어 포함뿐 아니라 부정·행위·수식 연산·수치 관계를 대조하고 로딩·번역 시간·생성 토큰·재시도·실패 수를 기록한다. 기존 실패를 숨기는 검증 완화는 품질 개선으로 집계하지 않는다.
4. 소규모 의미 품질이 개선된 후보만 강의 STT 36묶음으로 확대한다. 평가 결과를 제시한 뒤 API 모델·토크나이저·프롬프트 적용을 진행한다. 지금 API 모델은 변경하지 않는다.
