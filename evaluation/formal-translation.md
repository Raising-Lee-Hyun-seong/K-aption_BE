# Qwen 존댓말 번역 검증

검증일: 2026-10-18. 기본 Qwen3 4B Instruct 2507에서 존댓말 지시를 시스템 메시지로 분리했다. 이전 영어 문맥은 같은 시스템 메시지의 별도 참고 부분으로 유지한다. 사용자 메시지의 수학·용어 보존 지시는 유지하고, 재시도에도 존댓말을 요청한다. Mac MLX와 CPU llama.cpp가 같은 구현을 사용한다. 모델 가중치·출력 한도·2회 시도 상한은 바꾸지 않았다.

`이다`, `한다`, `있다`, `진다` 등 뚜렷한 평서형 반말을 발견하면 `informal_speech`로 거부하고 다시 생성한다. 어미를 기계적으로 치환하지 않으며 두 번 모두 실패하면 기존 `translation_failed` 처리에 따른다. 이 검사는 명사구나 모든 한국어 종결형을 분류하는 문법 검사기가 아니다. `해요`체 질문도 존댓말로 허용한다. 명시적으로 선택하는 기존 KoreanLM에는 적용하지 않는다.

## 저장 STT 재생 결과

수식 결합을 적용한 같은 26구간을 실제 모델로 번역했다. 개발 입력의 프롬프트 비교이며 독립 평가가 아니다. 모든 보고서에 원문·시각·기존 구간 대응·모델과 구현 SHA256·검증 전 생성 시도를 보존했다. 아래 시간은 번역 호출 합계이며 로딩·STT·HTTP 전체 시간은 아니다.

| Mac MLX 조건 | 번역 반환 | 시도 수 | 번역 시간(초) |
| --- | ---: | ---: | ---: |
| 존댓말 적용 전 | 26/26 | 27 | 40.29 |
| 사용자 지시 끝에 긴 말투 지시 | 22/26 | 30 | 48.01 |
| 짧은 말투 지시 | 22/26 | 33 | 56.68 |
| 첫 번역 지시에 말투 명시 | 24/26 | 32 | 65.50 |
| 최종: 시스템 메시지에 말투 분리 | 25/26 | 28 | 45.69 |

최종 [MLX 결과](qwen-formal-mlx-v4-261018.json)의 반환된 25개 번역을 확인했다. `여기서 이 관계를 도출했습니다.`, `이것이 초기 질량입니다.`, `이 방정식은 우리에게 무엇을 알려주나요?`처럼 존댓말을 사용했다. 47.0–58.56초의 결합 구간은 두 번 모두 영어 수학 연산어가 남아 번역을 제공하지 못했다. 적용 전보다 반환 수가 1개 줄었으며, 말투 지시가 기존 생성 내용에 영향을 주는 한계가 있다.

**반환 수나 존댓말 사용은 의미 정확도가 아니다.** `rocket's lead`, `2 vR prime of t`, `u1 over m` 등의 STT 오류는 그대로 남는다. `원함니다` 같은 맞춤법 오류, `통합할 수 있습니다`처럼 문맥에 끌린 표현, 로그 괄호 범위와 수식 의미 문제도 확인됐다. 이번 구현이 전문 강의 번역 품질을 해결했다고 해석하지 않는다.

비교 원시 보고서: [첫 지시](qwen-formal-mlx-261018.json), [짧은 지시](qwen-formal-mlx-v2-261018.json), [첫 문장 지시](qwen-formal-mlx-v3-261018.json). 적용 전 기록은 [수식 결합 평가](math-grouping.md)에 있다.

## CPU 결과

고정 Qwen Q8_0·llama.cpp·4스레드·GPU 오프로딩 비활성화 조건에서 26구간을 다시 번역했다. [CPU 원시 결과](qwen-formal-cpu-261018.json)는 23개 반환·3개 실패·29회 시도·번역 합계 151.52초다. 반환된 23개 문장의 존댓말 사용을 확인했다. 예를 들어 마지막 구간은 `즉, 속도는 초기 속도에서 어떤 값이 빠진다는 뜻이며, 이는 속도가 감소한다는 뜻이고, 따라서 내 썰매는 결국 멈추게 됩니다.`로 나왔다.

실패는 47.0–58.56초, 127.4–141.32초, 156.89–171.65초의 수식 구간으로, 영어 연산어 잔류·기호 누락 검사를 통과하지 못했다. 적용 전 CPU 25/26보다 반환 수가 2개 줄었다. 검증을 완화해 부정확한 수식을 반환하지는 않았다. 이 측정은 Apple Silicon 네이티브 CPU이며 Windows 실기기나 Docker 에뮬레이션 속도를 의미하지 않는다.

## 검사와 적용

관련 단위 테스트 70개를 통과했다. 존댓말 지시·반말 후 실제 재시도 경로·2회 실패 상한·존댓말 질문·명사 오인 방지, STT 힌트 전달, 수식 결합·자막·파이프라인·미디어 제한·테스트 선택기를 검사했다. 전체 테스트 모음은 실행하지 않았다.

Windows 배포용 Linux amd64 Docker 이미지를 빌드했고, 이미지 내부에서도 번역·STT 힌트·수식 결합 테스트 21개를 통과했다. 이는 위 70개 중 일부를 다른 실행 환경에서 확인한 것이다.

Mac은 서버를 종료하고 `make api`로 다시 시작한다. Windows는 README의 `docker compose --env-file docker/cpu.defaults -f compose.cpu.yaml up -d --build backend`를 실행한다. 새로 접수한 작업부터 적용되며 이미 저장된 번역은 다시 업로드해 처리해야 한다.
